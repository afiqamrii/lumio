# Lumi individual reactions

Nine separately generated transparent PNG assets, matched to the expression sheet. Each contains one torso-up character, with no label or background. All source images are preserved without pixel editing. Every file is RGBA and has verified transparent pixels.

Open preview.html to compare the separate images. reactions-manifest.json maps stable IDs to filenames, dimensions, approximate visible bounds, usage and suggested copy. generation-prompts.json contains the exact per-image prompts used with built-in image generation.

## Using them
These are static UI reactions: use the image directly for greetings, hints, feedback and completion panels. Keep the PNG aspect ratio and use contain sizing. The lower torso is deliberately cut straight as a bust illustration. Alpha includes antialiased edges. Do not stretch or recolor automatically. Pair important feedback with visible text.

Same canvas sizes do not imply perfectly registered animation frames. Pose scale and silhouette vary slightly between generated assets. Cross-fading whole images is possible, but smoothly animating facial/limb parts requires a separate vector/layered rig or frame animation pass. No rig, frame sequence or animated files are included. Color-normalized vector masters remain pending.

Earlier sheet and usage notes remain in ../expressions/. Individual files are ready for visual review and static placement; not a claim of tiny-size or platform-specific validation.
