# Refined Lumio wordmarks

The owner selected the first Soft Round direction for refinement, with lowercase purple lettering and a small golden flame/drop above i. This supersedes the recommendation for Playful Bounce.

## Delivered variations
- A — Balanced Violet: balanced spacing, violet lettering and a tapered golden drop. Recommended main visual direction.
- B — Deep Violet: deeper purple, compact spacing and subtly altered drop.
- C — Open Lilac: brighter purple, more open spacing and a rounded drop with a short peak.
- Small UI alternate: simplified round golden dot, dark purple lettering, no decorative point. Provided as a small-placement design alternate, not a fourth main candidate.

All four are separate transparent PNGs made with built-in image generation. They are related refinements; minor letter-shape drift and fill variation remain in generated artwork. Intended HEX values in prompts are direction only, not verified flat spot-color values.

## Production status
These are polished raster proposals, not editable vector masters. The simplified forms are intended to support scalable reproduction, but PNG resolution is finite. Exact vector paths, final kerning, uniform colors and real small-size checks are still needed before calling a logo production-final. No minimum pixel size or accessibility contrast compliance is asserted. User has not chosen A, B or C yet.

Original mascot and previous drafts remain in the baseline folder. Exact prompts included. No font file is bundled or claimed.
