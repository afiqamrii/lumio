# Lumio editable / export assets

- logos/: custom SVG paths, monochrome/reverse variants and transparent PNGs.
- character/: full-body layered SVG, separated same-canvas parts, pivots, silhouette and replayable motion study.
- icons/: iOS asset catalog, Android resources, web exports and manifests.
- fonts/: actual licensed variable fonts, CSS and specimen.
- audio/: five original synthesized prototype WAV cues.
- tools/: reproducible source builders. Python 3; Node plus sharp for image exports. Font/PDF builders use fontTools, reportlab, pypdf and PyMuPDF.

See each directory README. New editable redraws retain the selected visual direction while flattening colors and simplifying outlines. Original approved PNGs remain alongside their earlier explorations. Device/game-engine checks happen during implementation.
