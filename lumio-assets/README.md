## What happens during implementation

The brand/design baseline is complete. Game code, playable lessons, engine-specific animation rigs, human voice/narration, curriculum/language review, device testing, accessibility validation and store submission belong to the game build. The included motion is a source study; the UI screens are mockups. Prototype audio requires final mixing and device listening. Icon exports are structurally checked, not store-approved.

Use CHECKS.md for validation scope and MANIFEST.json for hashes. Import the provided artwork and fonts into the engine of your choice; keep license files. Add your game structure to game-structure/ when ready.
